ACADEMIC PROJECT

About This Demonstration

EduSphere is an academic Web Technologies project created to demonstrate website structure, responsive design, navigation, forms and frontend development.

This website is a demonstration project. It does not provide real courses, real student accounts, real authentication or online learning services.

No personal account information is stored through the demonstration Sign In and Sign Up pages.
