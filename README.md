# EduSphere

EduSphere is an educational university website developed as a Web Technologies assignment.

## Project Overview

This project is an extension of the previous EduSphere website assignment. It includes the original website pages along with improved browser and mobile responsiveness features.

## Features

- Home Page
- About Page
- Contact Page
- Sign In Page
- Sign Up Page
- Dashboard Page
- EduSphere Favicon
- Responsive Mobile Navigation
- Clean and user-friendly interface
- HTML and CSS based design

## Technologies Used

- HTML5
- CSS3
- Tailwind CSS
